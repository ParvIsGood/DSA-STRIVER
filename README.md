# DSA-STRIVER

This repository contains my solutions to DSA problems from the Striver sheet and related practice sets.

## Repository Structure

- `Arrays/`
- `Binary Search/`
- `Binary Search on 2D/`
- `Binary Search on Answer/`
- `Linked List/`
- `Strings/`

Each file/folder generally represents one problem and includes a C++ solution (often with brute-force and optimal approaches).

## Purpose

- Track problem-solving progress
- Keep topic-wise DSA solutions in one place
- Use as a revision resource
